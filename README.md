# hack-skills

Four skills for winning hackathons, each owning one handoff. Built from the ShipGate (SF Enterprise Hackathon 2.0, Opsera) win.

| Skill | Job | Input → Output |
|---|---|---|
| `hackathon-seam-hunting` | Decide what to build | Sponsor docs + case studies + criteria + time budget → ranked seams, locked spec, frozen pre-registration, build acceptance criteria |
| `people-research` | Know the room | Names + context → power map, dossiers, talk tracks, question bank, event-conversion and post-win playbooks |
| `build-prompt` | Package the handoff to the builder | Locked spec → sequenced paste-ready prompt blocks (one at a time, go-word checkpoints, token budgets, verify each land) |
| `demo-ready` | Ship the submission | Working product → beats table, submission post, claim boundaries, verified repo |

Boundaries: seam-hunting ends at the locked spec; build-prompt starts there and ends at verified landed phases (the build itself is the builder's work, never the agent's); demo-ready starts only from a working product; people-research serves the other three and stands alone before any event.
